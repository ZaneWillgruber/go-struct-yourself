# go-struct-yourself

A personal practice repo for strengthening my grasp of data structures by implementing them from scratch in Go.

This isn't meant to be a library or used by anyone else. It's just for learning but feel free to use it if you want to.

## Structures

- `binarytree`: binary search tree (insert, find, delete, min/max, successor/predecessor, traversals)

## Running tests

```sh
go test ./...
```
